The type system

Three faces, three jobs. All are on Google Fonts. Search each by name in Canva's font menu; if one is missing, download it free from fonts.google.com and upload it to the Brand Kit. Canva's letter spacing slider uses thousandths of an em, so 0.16em on the website becomes 160 in Canva.

Grown slowly, dug daily, packed by hand.
Headlines · Baloo 2 ExtraBold
Weight 800, letter spacing −10, line height 1.05 to 1.1. Sentence case, never all caps. Big and confident: on a 1080px square post, 80 to 120px.

Body · Hanken Grotesk Regular
Weight 400 (600 for emphasis), line height 1.5 to 1.6, spacing 0. Keep lines short, around 60 characters. On a 1080px post, 30 to 36px.

Eyebrow labels · Hanken Grotesk SemiBold
The most recognisable Morghew device. Uppercase, weight 600, spacing 160, small (13px web, about 28px on a 1080 post). Hessian #6E5021 on paper, Straw #C9A24E on dark or photos. It sits above almost every headline.

One-time setup

Canva Brand Kit checklist

  1. Add the colours. In Canva go to Brand Kit and paste the palette: #F6F0EA #ECE2D1 #FBF7EF #281A12 #6A5A48 #C9A24E #E3C57F #0A5A4C #06372C #9E3A26 #6E5021 #B43C18 #C9761C #A27212 #4E7A5E #6B4A2A
  2. Set the fonts. Headings: Baloo 2 ExtraBold. Subheadings: Hanken Grotesk SemiBold. Body: Hanken Grotesk Regular. If any is missing from Canva's menu, download it free at fonts.google.com and upload to the Brand Kit.
  3. Upload the logos. Both lockups are already in Shopify under Content, then Files: Morghew_logo_white.png for photos and dark grounds, and the colour lockup for paper grounds. Download them from there and add to the Brand Kit logo slot.
  4. Pull real photography. The best assets are already in Shopify Files: the potato fields, the steam train, the woodland, the varieties. Download a starter set of 15 to 20 into a Canva folder called Estate Photography.
  5. Build the components page. Recreate each component above once in a scratch design, group each one, and keep it as your copy-from library.
  6. Remember the two rules. Harvest red is only for buy buttons, and one earthy accent per design.
